🏗️ Infrastructure as Code

IaC WebApps

A visual platform for designing infrastructure and generating production-ready Terraform, OpenTofu, Pulumi, or Helm code — with drag-and-drop design, cost estimation, and AI-assisted workflows.

View on GitHub Quick Start
ℹ️ This is a documentation page, not a live demo. The visual designer needs to persist local state and call third-party AI/pricing APIs, so it's best run locally rather than as a static demo. Spin it up with Docker in under a minute — see below.

Key Features

Multi-Tool Support

Switch seamlessly between Terraform, OpenTofu, Pulumi (TypeScript), and Helm Charts.

AI Copilot

Natural-language assistant (DeepSeek-V3 / GPT-4o) that adds resources to your design automatically.

Visual Designer

Drag-and-drop canvas powered by React Flow with synchronized editing and dependency mapping.

Cost Estimator

Real-time hourly/daily/monthly cost breakdown with live USD → IDR conversion.

Architecture Templates

Pre-configured blueprints — 3-Tier Network, Hybrid Cloud, Kubernetes Stack.

Security Scanner

Static analysis flags misconfigurations (public S3 buckets, open SSH ports) before deploy.

HCL Importer

Reverse-engineer existing Terraform .tf files into visual diagrams instantly.

Advanced Logic

Modules, remote state backends, and resource dependency chains.

Run it locally

git clone https://github.com/wahidhendrawan/iac-webapps.git
cd iac-webapps
docker compose up -d --build

Open http://localhost:8088. Alternatively run with Node.js 20+ and npm install && npm run dev.
